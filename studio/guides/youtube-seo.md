# YouTube SEO

- Title: keyword first, under 70 characters, no clickbait the video does not pay off.
  Example: "OpenLIT Enterprise: LLM Observability with RBAC, Audit Logs and Alerts".
- Description: first 2 lines carry the hook plus the main keyword and the CTA link. Then chapters (landscape),
  then links (site, docs, GitHub), then 3 hashtags.
- Tags: at most 15, each under 30 characters (the tool cuts longer ones). Mix brand, category and problem tags.
- Shorts: vertical 1080x1920, under 60 s. `post_youtube_short` adds #Shorts. Landscape videos posted through the
  same tool also get #Shorts, so fix the category and tag in Studio after posting if needed.
- Upload captions (`.srt`). Pin a comment with the question from the end card.
