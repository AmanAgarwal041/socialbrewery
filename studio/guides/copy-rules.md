# Copy rules (titles, posts, voiceover)

- No em dashes or en dashes anywhere. Use a period, a comma, or "and".
- Humor is welcome, but every line also carries a search keyword (for OpenLIT: LLM observability,
  OpenTelemetry, AI agent tracing, LLM cost tracking, GPU monitoring, prompt management).
- Lead with the pain, not the product. The product name arrives after the hook.
- Short sentences. One idea per sentence. Read it aloud: if you run out of breath, split it.
- End with an open question that invites comments ("What does your agent lie about?").
- Links go at the END of LinkedIn posts. On Slack, put extra links in the thread reply, not the main post.
- LinkedIn video posts: upload to YouTube first, then post on LinkedIn with the YouTube link as a preview
  card (`post_linkedin` with `linkUrl`). Link cards only form when the post is created, editing does not add one.
- Never claim features the product does not have. Pull feature names from the docs or the PR.
