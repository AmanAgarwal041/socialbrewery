# Brag-style storytelling
> Turn a PR, changelog or docs page into a short story: inspect the real change, plan beats, compose, deliver.

Full method: `studio://vendor/brag/SKILL.md` (steps 1 to 4 and tones).

1. Inspect: read the PR, changed files and docs. List what the user can now do that they could not before.
2. Plan: problem -> moment of change -> 3 proof beats -> invitation. Pick a tone (playful, confident, technical).
3. Compose: one scene per beat with real screenshots from the merged main branch.
4. Deliver: both cuts, captions, poster, plus post copy for each network.
